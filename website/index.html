这个项目把分散在浏览器里的重复操作，收拢到一个桌面窗口。浏览器负责承载页面与登录状态，桌面端负责参数、监控、控制和反馈。

它的重点，是让自动化过程有状态可看、有日志可查，也有明确的停止入口。

需要开启真实提交吗？

可以先只监控。首次运行默认关闭真实提交和自动启动；后续开关会保存在本地，每次使用都应检查当前模式。真实提交会使用登录账户发起跟单申请，可能转入 USDT 并带来合约风险。项目不保证取得名额或收益。

可以放到云端一直运行吗？

当前版本适合带图形桌面的 Windows 云服务器或云电脑，需要安装浏览器并重新登录。远程桌面断开后的会话保留取决于服务器策略。登录过期、浏览器恢复、错误退避和远程告警尚不完整，持续无人值守前应先验证并完善这些能力。

启动异常，或者页面一直报错怎么办？

启动异常可使用「启动-调试模式.bat」查看错误。页面持续报错时，先停止尝试，检查网络、登录状态和平台提示。网页内部模块变化需要重新适配；「项目已满」只是页面响应，并不表示已经成功。

这是币安官方项目吗？

这是独立的个人开发作品，与币安官方没有隶属或背书关系。当前软件入口域名及其跳转来源尚未核验，输入登录凭证前请自行确认实际页面可信。源码和完整限制说明均可在 GitHub 查看。
